Key Features

What this project demonstrates.

Containerized Application

The Flask application runs inside an isolated Docker container with its required dependencies.

Private Image Registry

The Docker image is stored in Amazon ECR before being deployed to ECS.

Serverless Containers

ECS Fargate runs the container without requiring manual EC2 server management.

Scalable Architecture

ECS services can maintain the desired number of running application tasks.

Environment Configuration

Application settings are separated from the application code using environment variables.

AWS Cloud Deployment

The application is deployed and accessible through AWS infrastructure in the Mumbai region.
